# DAFAN RE PRO v3.0

تطوير تراكمي لمشروع v2 الأصلي، Android Java، package: `com.dafan.re`.

## المنفذ في هذا الإصدار
- الإبقاء على اختيار الملفات والمجلدات عبر Android SAF، واستخراج ZIP/APK/JAR/OBB بصورة متدفقة.
- الإبقاء على استخراج أقسام ELF الحقيقية من جدول الأقسام (32/64-bit وLittle/Big Endian ضمن حدود جدول الأقسام التقليدي).
- إضافة فحص ASCII الموجود في v2، وإضافة استخراج نصوص UTF-16LE/BE (استخراج تقريبي للنصوص القابلة للطباعة).
- إضافة بحث Hex Pattern مع تسجيل إزاحات المطابقة.
- إضافة معاينة Hex لأول 4KB إلى ملف نصي (قراءة فقط؛ ليس محرر تعديل).
- إضافة تقريري TXT وJSON لمعلومات الملف الأساسية.
- إضافة زر إيقاف، ومؤشر تقدم للعمليات التي تبلغ عن تقدمها.
- واجهة RTL عربية داكنة.
- المعالجة المحلية ونسخ البيانات على دفعات، دون تحميل الملف كاملاً إلى RAM في مسارات النسخ/البحث.

## غير منفذ / حدود صريحة
- تحليل ELF المتقدم لـ Symbols وImports وExports وDependencies غير منفذ بعد. استخراج الأقسام لا يعني تحليل جدول الرموز.
- دعم معماريات ARM/ARM64/x86/x86_64 لا يعني فك تعليمات أو Disassembly؛ لا يوجد Disassembler.
- لا يوجد محرر Hex لتعديل الملف الأصلي أو كتابة تغييرات عشوائية؛ المتاح حالياً معاينة Hex فقط.
- File Carving في v2 يكتشف بعض التواقيع ويكتب سجل إزاحة فقط. لا يدّعي استخراج صورة/فيديو/صوت سليمة، ولا يحسب حدودها أو يتحقق من سلامتها.
- Unreal PAK وIoStore/UTOC/UCAS وتحليل فهارسها واستخراج UASSET/UEXP/UBULK غير منفذ. لا يتم إنشاء ملفات Unreal مصطنعة.
- لا يوجد فك تشفير؛ الحاويات المشفرة تحتاج مفاتيح صحيحة ودعم صيغة/نسخة الحاوية.
- لا يوجد فك ضغط Unreal Oodle أو Zlib/LZ4 متخصص للحاويات. ZIP القياسي فقط مدعوم عبر مكتبات Java.
- بعض مزودي SAF لا يوفرون FileChannel أو Random Access؛ استخراج ELF يتطلب descriptor قابل للبحث.
- ELF extended section numbering غير مدعوم.

## بناء APK من الهاتف
1. ارفع محتويات مجلد `DAFAN_RE_PRO` إلى مستودع GitHub (جذر المستودع يحتوي `settings.gradle`).
2. افتح تبويب Actions وشغّل **Build DAFAN RE PRO APK** أو ادفع commit إلى main/master.
3. نزّل artifact باسم `DAFAN-RE-PRO-debug` وثبّت `app-debug.apk`.
4. يمكن فتح المشروع في AndroidIDE مع JDK 17 وGradle 8.9 وAndroid SDK 35.

## متطلبات البناء
- Android Gradle Plugin 8.7.3
- Gradle 8.9
- JDK 17
- compileSdk 35 / minSdk 23

استخدمه فقط على ملفات تملكها أو لديك تصريح لتحليلها. لا تشغّل الملفات المستخرجة.
